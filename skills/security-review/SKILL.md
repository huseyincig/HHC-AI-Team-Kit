# Güvenlik İncelemesi

Auth/authz, izin, gizli bilgi, kullanıcı kontrollü girdi, DB/dosya mutasyonu, upload, ağ yüzeyi, dependency/supply-chain, serialization, crypto veya production sınırı gerçekten etkileniyorsa gerçek veri/çağrı akışını incele. Kanıtsız CVE veya genel korku listesi üretme; güvenlik etkisi yoksa kapsamı büyütme.
