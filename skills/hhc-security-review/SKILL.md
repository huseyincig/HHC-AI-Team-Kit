# Güvenlik İncelemesi

Kimlik doğrulama/yetkilendirme, izin, gizli bilgi, kullanıcı kontrollü girdi, DB/dosya mutasyonu, dosya yükleme, ağ yüzeyi, bağımlılık/tedarik zinciri, serileştirme, kriptografi veya üretim sınırı gerçekten etkileniyorsa gerçek veri/çağrı akışını incele. Kanıtsız CVE veya genel korku listesi üretme; güvenlik etkisi yoksa kapsamı büyütme.
